# 测试汇总

测试日期：2026-11-17

候选实现：当前仓库，libopenmpt `0.9.0-pre.13`，ASan + UBSan + LSan。

参考实现：系统包 libopenmpt `0.8.4`
（`/usr/lib/x86_64-linux-gnu/libopenmpt.so.0`）。

四类用例各 50 例，按 `N % 4` 严格交替：

| 类别 | 用例 | 加载 | 拒绝 | 失败 |
| --- | ---: | ---: | ---: | ---: |
| 截断 | 50 | 11 | 39 | 0 |

每个用例在独立进程中运行，超时 12 秒。失败结果包含
`mutation_offset`、`failure_offset` 和 `failure_report`，偏移是首个被删除或
修改的字节。

## 反例

200 例没有发现实现失败，因此没有崩溃/越界/泄漏型反例。`counterexamples/`
保存了 15 个有代表性的对抗输入，覆盖四类问题和四种格式，并带精确偏移和
JSON 元数据。它们属于安全拒绝或有限渲染的回归样本，不是实现缺陷。
